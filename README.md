# طرح ۳ — لندینگ پویای خورشیدی

**Bargheto's solar-electricity landing concept with enhanced motion and interactive income estimates.**

> **وضعیت:** پروژه آزمایشی طراحی و توسعه رابط کاربری است؛ ادعای استقرار عملیاتی، کاربران واقعی یا صحت تجاری ارقام ندارد.

## معرفی

این مخزن یکی از طرح‌های وب‌سایت برقتو برای معرفی تجمیع برق خورشیدی و تجربه فارسی راست‌به‌چپ است. هر مخزن یک پیاده‌سازی/نسخه مستقل از رابط کاربری را نگهداری می‌کند.

## قابلیت‌ها

- صفحه راست‌چین فارسی برای تجمیع و فروش برق خورشیدی
- محاسبه‌گر فرضی درآمد، فرم و FAQ
- انیمیشن‌های اسکرول با GSAP و ScrollTrigger
- اسکرول نرم با Lenis و واکنش‌های ماوس/کارت

## ساختار مخزن

- `index.html` — محتوای صفحه
- `styles.css` — استایل و جلوه‌های تصویری
- `script.js` — محاسبه‌گر، فرم، حرکت و تعامل

## اجرای محلی

پیش‌نیاز: یک مرورگر جدید؛ برای مدیریت درست مسیرها بهتر است یک سرور استاتیک محلی داشته باشید. از ریشه مخزن:

```bash
python -m http.server 8000
```

سپس `http://localhost:8000/` را باز کنید. به Build پیچیده یا Node.js نیازی نیست. برای بارگذاری GSAP، Lenis و فونت‌ها به دسترسی CDN نیاز است.

## نکات مهم

- نرخ‌ها، داده‌های عملکرد و خروجی ماشین‌حساب فرضی‌اند. فرم بدون اتصال تأییدشده به سامانه برقتو نباید به‌عنوان ثبت درخواست واقعی استفاده شود.
- ارسال اطلاعات شخصی، انتشار آمار عملکرد واقعی یا معرفی نرخ‌های بازار منوط به اتصال بک‌اند و تأیید داده‌هاست.
- قبل از بازنشر تصاویر، فونت‌ها و منابع بیرونی، مجوز استفاده را بررسی کنید.
- این مخزن بخشی از نمونه‌کارهای توسعه وب برقتو است و پروژه `smart-energy-city` مستقل از آن است.
